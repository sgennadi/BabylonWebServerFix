# BabylonWebServerFix v1.0.6 Stable

Stable Windows x64 self-contained .NET 10 release for Babylon Pro 12, IIS and Apache/XAMPP.

## New: Babylon tray initialization

On a fresh user profile, Babylon can initially open its main window even when started with `-AutoStart`. After its first minimize-to-tray, Babylon may remember that behavior.

This release adds an **explicit, opt-in** `tray-init` command that sends Windows `WM_SYSCOMMAND / SC_MINIMIZE` to the existing visible Babylon window under the current interactive user. Unlike copying binary configuration data, it leaves Babylon's license, registry data and files untouched.

```cmd
BabylonWebServerFix.exe tray-init
BabylonWebServerFix.exe tray-init --wait-seconds 45
BabylonWebServerFix.exe tray-init --dry-run
```

- Run as the signed-in user (e.g. `Student`), **not** as SYSTEM or a different elevated administrator.
- `--wait-seconds` accepts 0..300 seconds to allow Babylon to start through its normal logon entry.
- Does not install an autorun entry, start Babylon, or modify IIS, Apache or WinINet.
- Safely limits the operation to Babylon owned by the calling user in the same interactive session.
- No effect if Babylon is already in the tray or has no visible main window.
- The separately tested PowerShell minimize technique worked on the user's workstation; validate the compiled EXE on a new profile before mass deployment.

## Previous compatibility features preserved

- Plain `install` chooses MSI-free IIS Native Request Filtering by default.
- Optional `--iis-mode rewrite` uses the Microsoft-signed URL Rewrite MSI when required.
- Apache/XAMPP integration, cache actions, managed removal and `status` behavior unchanged.
- No-argument invocation displays help without making changes.

## Assets

- `BabylonWebServerFix.exe` — unsigned, self-contained .NET 10 Windows x64 executable.
- `SHA256SUMS.txt` — SHA-256 checksum for the executable.

Use `install` only when Babylon's localhost UI actually conflicts with IIS or Apache. `tray-init` is independent of the web-server fix.
