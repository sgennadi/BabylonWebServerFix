# BabylonWebServerFix v1.0.5 Stable

Stable self-contained Windows x64 release of the Babylon Pro 12 IIS / Apache compatibility utility.

## Changes
- Starting the EXE with no arguments now shows help and usage examples without changing IIS, Apache, Babylon or caches.
- The Windows `/?` switch shows help, alongside `-h` and `--help`.
- Configuration changes require an explicit `install` command.
- Updated smoke tests and README instructions.
- Retains the v1.0.4 built-in IIS Request Filtering default, opt-in Microsoft URL Rewrite, Apache/XAMPP support, and managed rule removal.

## Usage
```cmd
BabylonWebServerFix.exe
BabylonWebServerFix.exe /?
BabylonWebServerFix.exe status
BabylonWebServerFix.exe install --dry-run
BabylonWebServerFix.exe install
BabylonWebServerFix.exe install --iis-mode rewrite
BabylonWebServerFix.exe remove-iis
```

Do not run `install` when Babylon already translates correctly with local IIS or Apache active.

## Assets
- `BabylonWebServerFix.exe`: Windows x64 self-contained .NET 10 application (unsigned).
- `SHA256SUMS.txt`: checksum for verifying the executable.
