# BabylonWebServerFix v1.0.0

**First stable Windows x64 release** of BabylonWebServerFix, a self-contained C# / .NET 10 command-line utility for Babylon Pro 12 compatibility with Microsoft IIS and Apache HTTP Server/XAMPP.

## Release assets

- **BabylonWebServerFix.exe** — standalone Windows x64 executable; does not require a separately installed .NET runtime or PowerShell scripts.
- **SHA256SUMS.txt** — SHA-256 digest for validating the downloaded executable.
- The source archives are automatically provided by GitHub.

## Features

- **IIS:** install the official Microsoft URL Rewrite 2.1 MSI when necessary, verify its Authenticode trust and Microsoft signer using the Windows WinTrust API, create or recognize the narrowly scoped Babylon 12 `localhost` AbortRequest rule, and back up IIS configuration.
- **Apache/XAMPP:** find Apache 2.4, create or recognize its managed compatibility rule, validate configuration using `httpd -t`, back up `httpd.conf`, and restart only the selected running Apache instance when a configuration update is required. Repeating `install` with unchanged Apache rules skips the restart.
- **Babylon:** stop and restart only a previously running Babylon instance, in the original interactive user session, when a safe non-elevated restart can be prepared.
- **Legacy WinINet:** clear temporary cache for non-special Windows user profiles while preserving cookies/saved credentials by design.
- **CLI:** `install` (also the default with no arguments), `status`, `remove`, `cache-only`, `restart-apache`, `--dry-run`. Logging and next-logon cache cleanup remain **off by default**.
- Does not alter DHCP, static IP addresses, IIS/Apache port bindings, Babylon installation files or licenses.

## Verification and scope

- C#/.NET 10 builds on Windows GitHub Actions, with automated offline smoke tests and a self-contained executable startup check performed before publication.
- The earlier v0.1.3 Preview binary was SHA-256 verified against the GitHub Release artifact on a Windows test station.
- Babylon Pro 12 translated correctly with **IIS running on port 80** after installing URL Rewrite and the managed rule.
- Babylon Pro 12 also translated with **XAMPP Apache running on TCP/80** after applying and restarting its managed rule.
- The v1.0.0 executable preserves the verified functional logic; the new binary still warrants a staged rollout.

**Known limitations:** IIS `AbortRequest` and Apache HTTP `403` are different responses. A normal `http://localhost/` page, multi-user/GPO/SYSTEM deployment, a completely absent web-server scenario, and other advanced options have not been fully demonstrated on target workstations. The binary is **unsigned**; Microsoft Defender SmartScreen/application-control may prompt or block it. Review the [test matrix](https://github.com/sgennadi/BabylonWebServerFix/blob/main/docs/TEST_MATRIX.md) for further validation gaps.

## Installation

Download `BabylonWebServerFix.exe` from **Assets**, verify the SHA-256 from `SHA256SUMS.txt`, then open **Command Prompt (Run as administrator)** and run:

```cmd
BabylonWebServerFix.exe status
BabylonWebServerFix.exe install --dry-run
BabylonWebServerFix.exe install
```

The EXE also supports `BabylonWebServerFix.exe --help`. Test on one workstation before broad deployment.
